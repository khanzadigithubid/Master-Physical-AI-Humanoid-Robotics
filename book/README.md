# Physical AI & Humanoid Robotics Textbook

## AI-Native University-Level Textbook

A comprehensive, production-ready textbook on Physical AI and Humanoid Robotics built with Docusaurus.

---

## Features

✨ **University-Level Content**: 6 modules, 24 chapters covering robotics fundamentals through humanoid systems

🤖 **AI-Native**: Designed for RAG chatbot integration, personalization, and Urdu translation

📚 **Production-Ready**: Technical depth suitable for senior engineers and academic instruction

🔧 **Practical**: Python code examples, ROS 2 integration, simulation labs

---

## Quick Start

### Installation

```bash
npm install
```

### Local Development

```bash
npm start
```

This starts a local development server at `http://localhost:3000`.

### Build

```bash
npm run build
```

Generates static files in `build/` directory.

### Deployment (GitHub Pages)

```bash
npm run deploy
```

## Content Structure

### ✅ Module 1: Introduction to Physical AI (Complete)
- Overview of Physical AI
- Formal mathematical definition
- Curriculum guide
- Prerequisites

### ✅ Module 2: Robotics Fundamentals (Kinematics Complete)
- **Kinematics** (forward/inverse, Jacobians, DH parameters)
- Dynamics (Euler-Lagrange equations)
- Control Theory (PID, LQR, MPC)
- Actuators & Sensors

### 📝 Module 3: Perception Systems
- Computer Vision
- LiDAR & Point Clouds
- Sensor Fusion
- SLAM

### 📝 Module 4: AI for Robotics
- Reinforcement Learning
- Imitation Learning
- World Models
- Foundation Models

### 📝 Module 5: Humanoid Robotics
- Bipedal Locomotion
- Manipulation
- Human-Robot Interaction
- Whole-Body Control

### 📝 Module 6: Deployment & Ethics
- Sim-to-Real Transfer
- Safety Systems
- Ethical Considerations
- Future Directions
