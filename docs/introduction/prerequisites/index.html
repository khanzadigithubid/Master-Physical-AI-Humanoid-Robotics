Linear Algebra​

Vectors and Matrices​

Vectors represent positions, velocities, forces:

v=[v1v2v3]∈R3\mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ v_3 \end{bmatrix} \in \mathbb{R}^3v=​v1​v2​v3​​​∈R3

Matrices represent transformations (rotations, projections):

A=[a11a12a21a22]∈R2×2A = \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \in \mathbb{R}^{2 \times 2}A=[a11​a21​​a12​a22​​]∈R2×2

Matrix-vector multiplication:

Av=[a11v1+a12v2a21v1+a22v2]A\mathbf{v} = \begin{bmatrix} a_{11}v_1 + a_{12}v_2 \\ a_{21}v_1 + a_{22}v_2 \end{bmatrix}Av=[a11​v1​+a12​v2​a21​v1​+a22​v2​​]

Key Operations​

  • Transpose: ATA^TAT, swap rows and columns
  • Inverse: A−1A^{-1}A−1, satisfies AA−1=IAA^{-1} = IAA−1=I
  • Determinant: det⁡(A)\det(A)det(A), scales volume
  • Eigenvalues/eigenvectors: Av=λvA\mathbf{v} = \lambda \mathbf{v}Av=λv

Robotics Applications​

  • Rotation matrices: R∈SO(3)R \in SO(3)R∈SO(3) (special orthogonal group)
  • Jacobians: Relate joint velocities to end-effector velocity
  • Inertia matrices: M(q)M(q)M(q) in dynamics equations

Python Example:

import numpy as np

# Rotation matrix (90° about z-axis)
R_z = np.array([
    [0, -1, 0],
    [1,  0, 0],
    [0,  0, 1]
])

# Apply rotation to vector
v = np.array([1, 0, 0])
v_rotated = R_z @ v  # Result: [0, 1, 0]

Calculus​

Derivatives​

Derivative measures rate of change:

f′(x)=lim⁡h→0f(x+h)−f(x)hf'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}f′(x)=h→0lim​hf(x+h)−f(x)​

Gradient for multivariable functions:

∇f(x1,x2)=[∂f∂x1∂f∂x2]\nabla f(x_1, x_2) = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \frac{\partial f}{\partial x_2} \end{bmatrix}∇f(x1​,x2​)=[∂x1​∂f​∂x2​∂f​​]

Optimization​

Find x∗\mathbf{x}^*x∗ that minimizes f(x)f(\mathbf{x})f(x):

x∗=arg⁡min⁡xf(x)\mathbf{x}^* = \arg\min_{\mathbf{x}} f(\mathbf{x})x∗=argxmin​f(x)

Gradient descent:

xt+1=xt−α∇f(xt)\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha \nabla f(\mathbf{x}_t)xt+1​=xt​−α∇f(xt​)

Robotics Applications​

  • Inverse kinematics: Solve for joint angles via optimization
  • Trajectory optimization: Find smooth paths
  • Neural network training: Backpropagation is gradient descent

Python Example:

import torch

# Define loss function
def loss(x):
    return (x - 3)**2 + 5

# Optimize with gradient descent
x = torch.tensor([0.0], requires_grad=True)
optimizer = torch.optim.SGD([x], lr=0.1)

for _ in range(100):
    l = loss(x)
    l.backward()
    optimizer.step()
    optimizer.zero_grad()

print(f"Optimal x: {x.item()}")  # Should be close to 3.0

Expectation:

E[X]=∑xxP(X=x)or∫xp(x)dx\mathbb{E}[X] = \sum_x x P(X=x) \quad \text{or} \quad \int x p(x) dxE[X]=x∑​xP(X=x)or∫xp(x)dx

Gaussian Distribution​

Most important distribution in robotics:

p(x)=12πσ2exp⁡(−(x−μ)22σ2)p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)p(x)=2πσ2​1​exp(−2σ2(x−μ)2​)

Notation: X∼N(μ,σ2)X \sim \mathcal{N}(\mu, \sigma^2)X∼N(μ,σ2)

Multivariate Gaussian:

p(x)=1(2π)n/2∣Σ∣1/2exp⁡(−12(x−μ)TΣ−1(x−μ))p(\mathbf{x}) = \frac{1}{(2\pi)^{n/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\mu)^T \Sigma^{-1} (\mathbf{x}-\mu)\right)p(x)=(2π)n/2∣Σ∣1/21​exp(−21​(x−μ)TΣ−1(x−μ))

Bayes' Rule​

Update beliefs given observations:

p(x∣y)=p(y∣x)p(x)p(y)p(x \mid y) = \frac{p(y \mid x) p(x)}{p(y)}p(x∣y)=p(y)p(y∣x)p(x)​

Robotics Applications​

  • Sensor noise: Modeled as Gaussian
  • Kalman filters: Optimal state estimation under Gaussian assumptions
  • Localization: Bayesian filtering for robot position

Python Example:

ROS 2 Basics​

ROS 2 (Robot Operating System 2) is the standard middleware for robotics.

Core Concepts​

Nodes: Independent processes (e.g., camera driver, planner)

Topics: Message passing (publish/subscribe)

Services: Request/response (e.g., "compute inverse kinematics")

Actions: Long-running tasks with feedback (e.g., "move to goal")

Example: Publisher/Subscriber​

Publisher:

import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class Publisher(Node):
    def __init__(self):
        super().__init__('publisher')
        self.pub = self.create_publisher(String, 'topic', 10)
        self.timer = self.create_timer(1.0, self.publish)

    def publish(self):
        msg = String()
        msg.data = 'Hello, ROS 2!'
        self.pub.publish(msg)

rclpy.init()
node = Publisher()
rclpy.spin(node)

Subscriber:

class Subscriber(Node):
    def __init__(self):
        super().__init__('subscriber')
        self.sub = self.create_subscription(String, 'topic', self.callback, 10)

    def callback(self, msg):
        self.get_logger().info(f'Received: {msg.data}')

rclpy.init()
node = Subscriber()
rclpy.spin(node)
